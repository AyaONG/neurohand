## A. Маршрут

Новые занятия сохраняют `attempts.flow` версии `hands-free-v1`: отдельные исходы попыток и причины закрытия целей. По умолчанию автоматические переходы включены; ручной режим снимает лимиты повторов/времени. Прототипные параметры: две оценённые неуспешные попытки, две отдельно начатые неоцениваемые попытки, 20 секунд пригодного времени после готовности, переход 3 секунды. Это продуктовые параметры, не медицинские нормы.

Часы цели включают ожидание движения после подготовки; паузы, пропуски кадров, потеря руки, неоднозначность и переходы исключены. Две подряд технически неоцениваемые цели требуют устойчивой видимости с отсчётом. Каждая новая цель вновь проходит подготовку. Пропуск — причина цели, без выдуманной попытки. Счётчики успешных движений не увеличиваются от перехода.

До запуска можно дополнить выбранное занятие базовой программой, выбранными парами и кольцом. Блоки связаны `attempts.route.trainingRunId`, имеют заранее выделенные sessionId; итог блока сохраняется до запуска следующего. Перезагрузка между этими действиями восстанавливает следующий блок, не включая камеру автоматически. Экспериментальные пары требуют явного выбора. Итоги показывают завершённые блоки и фактические успехи.

Схема сессии остаётся v3: новые поля строго проверяются внутри JSON попыток. Старым снимкам связи не добавляются; сравнение учитывает версию переходов, автоматический/ручной режим и маршрут. Существующая SQL-миграция допускает эти вложенные агрегаты; новая SQL-миграция не требуется. RLS и облачный транспорт не изменены.
