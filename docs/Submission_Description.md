# Описание для формы

NeuroHand — браузерный прототип тренировки движений кисти с обычной веб-камерой. Пользователь последовательно собирает пять огоньков пинцетным захватом, пять раз сжимает виртуальный мягкий мяч и проводит указатель открытой ладони в три цели с удержанием по две секунды. MediaPipe распознаёт ориентиры кисти; приложение связывает подтверждённые движения с результатом, подсвечивает ошибочный палец или неполное сжатие мизинца и даёт текстовую подсказку.

После программы автоматически открываются итоги: выполненные действия, активное время, эпизоды подсказок и лучшее удержание. «Мой прогресс» хранит до 30 тренировок в этом браузере, показывает историю и семь дней активности. Сопоставимые завершённые сессии можно увидеть рядом. Прерванную тренировку можно продолжить после повторной подготовки руки. Видео и координаты руки в пользовательскую историю не сохраняются; аккаунты, серверная обработка и синхронизация между устройствами отсутствуют.

Стек: TypeScript, Vite, MediaPipe Hand Landmarker, Canvas, SVG/CSS и localStorage.

## Сведения для заполнения полей формы

- Репозиторий: https://github.com/AyaONG/neurohand — публичность проверена. Финальная локальная ветка на момент проверки ещё не опубликована; перед сдачей нужно проверить наличие версии, описанной здесь.
- Рабочая HTTPS-ссылка: пока не подтверждена; заполнить только после публикации и ручного прохождения.
- Автоматические проверки: 74 теста и production-сборка прошли; файлы production preview проверены по HTTP.
- Реальная камера, другая рука/другой человек и второе устройство: не проверены в доступной среде. Результаты живого испытания можно добавить только после фактического прохождения.
- Не заявлять точность распознавания в процентах, восстановление функций кисти, оценку усталости, клиническую эффективность, PDF-отчёты, облачную историю или проверенную мобильную поддержку: таких подтверждённых возможностей нет.
