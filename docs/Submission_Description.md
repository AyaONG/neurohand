# Описание для формы сдачи

## Краткое описание

NeuroHand — браузерный прототип тренировки движений кисти с обычной веб-камерой. MediaPipe распознаёт ориентиры руки локально; игровые задания дают визуальные подсказки и сохраняют полные и частичные результаты без записи видео в историю.

**Приложение: [https://neurohand.vercel.app/](https://neurohand.vercel.app/)**

## Текст проекта

В NeuroHand есть базовая программа из пяти пинцетных захватов, пяти сжатий и трёх удержаний раскрытой ладони, режим «Найди пару» и «Обведи кольцо» с 12 последовательными отметками. Пользователь выбирает удобные пары пальцев и кончик для кольца, объединяет упражнения в маршрут. Автоматические переходы позволяют завершить занятие с частичными результатами, без требования бесконечно добиваться идеала. Шесть пар без большого пальца отмечены как экспериментальные и включаются явно.

Приложение различает цель и попытки её достижения, показывает число попыток до успеха, выполненные и пропущенные цели, активное время и конкретные метрики упражнения. Ошибки отслеживания не выдаются за неудачи человека. История фильтруется по периоду, упражнению и руке; сравниваются только сопоставимые настройки и версии правил. PDF с кириллицей можно скачать для занятия или выбранной истории, JSON — для резервной копии и переноса.

Без входа результаты сохраняются в этом браузере. Необязательный Google-вход через Supabase открывает синхронизацию: локальная очередь переживает перезагрузку, повторная отправка не создаёт дубликат, статус аккаунта подтверждается серверным ответом. Гостевая история переносится только по явному выбору. В облако отправляются агрегаты и результаты попыток, без видео и потока ориентиров руки.

Стек: TypeScript, Vite, MediaPipe Hand Landmarker, Canvas/SVG/CSS, localStorage, Supabase Auth/PostgreSQL с RLS, pdf-lib/fontkit; тесты — Vitest. NeuroHand описывает выполнение заданий, не ставит диагнозы и не заявляет клиническую эффективность или измерение восстановления.
