## Что проверить вручную (шесть сценариев)

1. **Гость на публичном URL:** открыть без аккаунта разработчика; без облачных env базовые упражнения доступны. Проверить камеру, модель и WASM без 404, консоль и Network: кадры/landmarks не отправляются.
2. **Камера — база:** обе руки, пинцет с раскрытием, сжатия, удержание. Проверить отсутствие повторных баллов за удержание, паузу/скрытую вкладку/потерю руки; итог и reload без дубликата.
3. **Камера — пары:** целевой средний принимается, указательный не даёт его успех; удержание не повторяет баллы, раскрытие открывает следующую попытку. Значимое неполное движение даёт partial, шум — нет. Проверить обе стороны кисти.
4. **Камера — кольцо:** полный путь с возвратом и отдельные 8/12, центр, скачок, исчезновение руки, пауза и resize. Курсор совпадает с кольцом при зеркальности. До подтверждения каждого нового режима оставить его production-флаг false.
5. **Два аккаунта:** реальный Google callback и reload; A → B во время задержанного запроса, гостевой импорт только выбранного занятия. Через API обычных A/B проверить чужой SELECT (пусто), чужой INSERT (отказ), anon SELECT/INSERT (отказ), запрет UPDATE. Не подменять проверкой администратора.
6. **Два устройства:** на первом A закончить занятие и дождаться «Сохранено в аккаунте»; на втором A обновить историю и сверить метрики, повторить reload без копии. На первом отключить сеть после загрузки, закончить ещё одно занятие и восстановить сеть — одна запись. Отдельно проверить предупреждение при отказе localStorage: без подтверждения сервера данные в памяти могут пропасть.
