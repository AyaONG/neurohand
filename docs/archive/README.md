# Архив NeuroHand

Здесь сохранены исторические отчёты, планы и исходные инструкции разработки. Их числа тестов, названия веток, ссылки на отсутствовавшие тогда функции и команды описывают состояние своего этапа, а не текущий продукт. Не запускайте начальную очистку/создание проекта из старых GUIDE/RUNBOOK.

Содержимое перенесённых файлов сохранено; изменены только относительные Markdown-ссылки там, где этого требует новый путь. Упоминания старых путей внутри исторических промптов и команд оставлены как часть оригинала. Расширенный план из `Documents/neurohand` не находился в этом репозитории и сюда не копировался.

Актуальные документы: [README](../../README.md), [запуск](../Launch.md), [облако](../Cloud_Setup.md), [описание для сдачи](../Submission_Description.md).
