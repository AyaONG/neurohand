# Краткие сбои распознавания пар

Ветка: feature/neurohand-attempts. Исходное рабочее дерево чистое. Изменены только обработка пар, её интеграция, проверки и этот отчёт. .env.local не читался и не изменялся.

## Поведение

- Отдельные причины и подсказки: наложение кончиков; различие оценённой глубины; третий близкий кончик; одновременно сближенные пары. Причина хранится в текущем Reading для диагностики, не в потоке истории.
- Один неоднозначный кадр не завершает попытку. Подтверждение успеха, фильтр и таймер возврата сбрасываются; измеряемое время и прогресс замораживаются. Сохраняются attemptId и уже наблюдённые метрики.
- Для восстановления нужны 250 мс устойчивой видимости. Эти интервалы также не включаются в активное время. Затем подтверждение успеха набирается заново, без переноса через сбой.
- Если до восстановления неоднозначность наблюдается 600 мс, попытка завершается один раз как unscorable. Повторяющийся сбой с короткими проблесками видимости не накапливает успех.
- После прерывания цель не меняется. Повтор — после раскрытия, устойчивой исходной позы и нового движения. Ручное завершение, пауза или остановка во время неопределённости также не записывают человеческую неудачу.
- Подсказка экспериментальных пар предлагает маленький видимый зазор: перекрытие не является успехом или доказательством касания.
- Счётчики разделены: «Выполнено: … / … · Пропущено: … · Попытки: … оценённых». Сбои и пропуски в оценённые попытки не входят; номер текущей попытки остаётся отдельным.
- Версии распознавания новых занятий обновлены, чтобы история не сравнивала их со старыми как одинаковые условия. Старые версии по-прежнему читаются без переписывания.
- Пороги и алгоритм базового пинцета не менялись.

600/250 мс — начальные параметры обработки сбоя; пригодность этих задержек на реальной камере пока не подтверждена.

## Проверки

215 тестов / 20 файлов проходят; production-сборка и git diff --check проходят. Новые сценарии: четыре причины неоднозначности, одиночный кадр, устойчивое перекрытие, мерцающий сбой, сброс подтверждения, повтор после раскрытия, ручное завершение/пауза/остановка, старые снимки. Существующие тесты неправильной пары, удержания и пропуска также проходят.

Тесты интерфейса явно отключают облачные env в своём окружении, чтобы локальный .env.local не менял их начальное состояние. Сам файл не изменяется.

Настоящая камера **не проверена**: попытка подключения браузера вернула «No browser is available», список подключённых браузеров пуст. Синтетические landmarks и тестовый DOM не заменяют камеру.

## Ручная проверка после обновления локальной страницы

1. Выбрать пару с большим пальцем: выполнить и удержать 3 секунды — один успех. Раскрытие разрешает следующую цель; базовый пинцет работает по прежним правилам.
2. В экспериментальной паре начать сближение, кратко перекрыть кончики и снова показать их раздельно. Попытка не должна сразу завершиться; подтверждение после восстановления начинается заново.
3. Держать кончики перекрытыми более 0,6 с: один результат «Не удалось оценить», сохранён прежний прогресс, успех не начислен. После раскрытия и подготовки повторяется та же цель.
4. Сблизить неправильную пару, затем раскрыть: выбранная цель не выполнена. Повторить правильной парой; убедиться, что подсветка соответствует ей.
5. Нажать «Пропустить» на неудобной цели: растёт только «Пропущено», «Выполнено» и число оценённых попыток не растут. Для демонстрации можно оставить только пары с большим пальцем.
